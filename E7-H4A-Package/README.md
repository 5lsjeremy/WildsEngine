# E7-H4A Recognized Geometry Population

H4A introduces an immutable scoped population of already-recognized geometry. It preserves exact recognition results, mapping identities, registration identity/version/scope and distinct semantic structures. It rejects unrecognized results, foreign mappings, unknown registrations and empty populations. It deliberately does not cluster, rank, average, select, congeal Truth, or project Consequences.

Extract at repo root, run `Install-E7H4A.ps1`, then `WildsEngine.Core.Tests\Entities\Runners\Invoke-E7H4A.ps1`.
