# Wilds.Discoveries S1 Consumer Surface

Implements S1A-D: current surface classification, `WildsDiscoveriesOptions`, typed geometry profiles, immutable/versioned geometry registrations, and the `WildsDiscoveries` public surface. Both programmatic profile registration and JSON mapping-document registration converge on the existing H3 mapping registry and projector machinery.

Extract at repository root, run `Install-S1.ps1`, then `WildsEngine.Core.Tests\Entities\Runners\Invoke-S1.ps1`.
