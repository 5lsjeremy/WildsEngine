# Wilds Product Family — 1.0 Product Canon

## QSL
**Stateful Processing.** Standalone controlled execution over consumer-owned objects and explicitly supplied runtime state. QSL is also included as the processing enhancement for Wilds offerings.

## Wilds Core
**Simulation Infrastructure.** Generic machinery for temporal processing, coordination, topology, propagation, emissions, relationships, and simulation mechanics.

## Wilds.Discoveries
**Knowledge and Emergent Narrative.** Epistemic processing from Evidence through Discoveries, knowledge geometry, competing narratives, scoped Truths, and Consequences.

## Wilds + QSL
**Programmable Simulation.** Wilds simulation plus QSL stateful execution.

## Wilds + QSL + Discoveries
**Flagship Integrated Stack.** Simulation + stateful processing + evolving knowledge + emergent narrative + scoped Truth + Consequence projection.

## Downstream ecosystem
Behavior systems, planners, LLM agents, engine integrations, and domain-specific add-ons may consume flagship output. They are not required product layers.

## Scope lock
No required product layer is added beyond Consequence projection without an explicit future scope decision.
