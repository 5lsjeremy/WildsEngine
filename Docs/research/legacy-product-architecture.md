# Legacy Product Architecture — Historical Note

**Status: superseded.**

Earlier product exploration treated Entities and optional Behavior/Agency layers as likely named product boundaries and considered additional suite-bridge composition.

The 1.0 canon supersedes that model:

- QSL: stateful processing.
- Wilds Core: simulation infrastructure.
- Wilds.Discoveries: knowledge and emergent narrative through Consequence.
- Wilds + QSL: programmable simulation.
- Wilds + QSL + Discoveries: flagship integrated stack.
- agency and behavior: downstream ecosystem work.

This file exists only to prevent older design language from being mistaken for current product scope.
