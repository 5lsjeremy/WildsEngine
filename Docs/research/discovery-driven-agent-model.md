# Discovery-Driven Agent Model — Historical/Future Research

**Status: research, not 1.0 product canon.**

This topic explores how downstream agent strategies might consume Wilds.Discoveries output while preserving information asymmetry, provenance, vocabulary boundaries, and simulation authority.

Potential strategies include reason/act/observe loops, plan-and-execute, reflection, orchestration, multi-agent coordination, and LLM-backed approaches.

None of these strategies is a required layer of the 1.0 flagship product. The current flagship stops at Consequence projection. Any future agency scope requires an explicit future scope decision.
