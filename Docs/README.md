# Wilds Product Family

**Build worlds without teaching the engine what your world means.**

Wilds is a modular product family for stateful processing, simulation, knowledge development, emergent narrative, and consequence-aware systems. The consumer owns domain meaning. Wilds supplies reusable machinery for processing it.

## Product family

### QSL — Stateful Processing
A standalone domain-neutral runtime over consumer-owned objects and explicitly supplied runtime state. Native bound-object properties are available immediately. Runtime properties become available only through explicit state attachment. Everything else remains unresolved.

QSL is independently useful and is also included as the stateful processing enhancement for Wilds product offerings.

### Wilds Core — Simulation Infrastructure
The domain-neutral simulation substrate: coordinated work, Pulse and WorkUnit execution, Moments, Timeline and Epoch history, topology, relationships, emissions, propagation, and processing infrastructure.

### Wilds.Discoveries — Knowledge and Emergent Narrative
The knowledge product. Its canonical progression is:

**Consumer Reality → Evidence → Proof → Facts → Discoveries → Knowledge Geometry / Momentum → Clusters → Scoped Truths → Consequences**

Authorization and observation describe how Evidence may be admitted. They are not additional canonical knowledge stages.

### Wilds + QSL — Programmable Simulation
Wilds simulation infrastructure plus stateful execution over consumer-owned runtime state.

### Wilds + QSL + Discoveries — Flagship Integrated Stack
Simulation, stateful processing, evolving knowledge, competing narratives, scoped Truths, and Consequence projection with attribution preserved across the route.

**Consequence is the current completion boundary. Agency begins after it.**

## Three rules

1. **The consumer owns meaning.**
2. **World state is not automatically entity knowledge.**
3. **Wilds may develop an answer, but must not hide where that answer came from.**

## Agency

Behavior trees, GOAP, utility AI, state machines, planners, LLM agents, and proprietary AI systems are downstream integrations. They may consume Wilds output, but none is required to complete the 1.0 flagship scope.
